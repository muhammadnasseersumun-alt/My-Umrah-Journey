# My Umrah Journey

A small personal landing page for a spiritual travel preparation experience focused on Umrah and Hajj.

## What is included

- A welcoming homepage for the journey
- Sections for preparation, checkpoints, spiritual focus, and itinerary
- A responsive design built with HTML, CSS, and JavaScript
- An interactive checklist for essentials

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project purpose

This repository is intended to capture the spirit of a meaningful pilgrimage journey and provide a simple, easy-to-use front-end experience for planning and reflection.
